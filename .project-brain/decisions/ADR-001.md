# ADR-001 — Hibrit kişisel kriterler ve sunucu sahipliği

30 Eylül 2026. Status: ACCEPTED mimari yön, kullanıcı tasarım seçimini devretti; implementation pilotla doğrulanacak. Gerekçe: hesap olmadan kişiye uygun ilan/push ve kesin ücretsiz servis gereksinimi.

## Seçenekler

| Yaklaşım | Sonuç |
| --- | --- |
| AI her kullanıcı profilini okuyup karar verir | Model işi ilan×kullanıcı büyür, özel veriyi modele taşır, aynı kriter için farklı karar riski; seçilmedi |
| Yalnız statik tag/topic | Ucuz ama score/age/alternatif kadro ve kişisel isimli kombinasyon için yetersiz; coarse index olabilir |
| Sınırsız serbest etiket + AI semantik match | Global sözlük kirlenmesi, keyfi anlamlar/maliyet; ilk sürümde seçilmedi |
| Typed ortak alanlar+sürümlü sözlük+kişisel saved search | Kesin validation/parity/index, kişisel isim esnekliği, AI notice başına; seçildi |

## Karar

Sunucu resmî notice'ı bir kez semantik revizyon başına AI ile zenginleştirir; doğrulanmış gruplar typed normal formda depolanır. İsimli kullanıcı araması kriter bileşimidir; global tag yaratmaz. Serbest sözcük deterministic q, profil modeleme gitmez. Match/no_match/unknown aynı conformance fixtures üzerinden server+client; silent eligibility guess yok. Çoklu kadro ayrı AND grubu/ANY alternatives. Notification new-event/outbox sahibi server, görünüm/token/permission sahibi mobil.

## Sonuç ve tavanlar

Dart core mobilde korunur; Worker native Dart runtime değildir, minimum TS/JS implementation ve JSON fixture parity gerekir. Serbest semantik soru/etiket çıkarımı future scope. Unknown şartlar strict push'u azaltır; ayrı kontrol-gereken listesi açıklanır. Indexed coarse supersets tam eşleşme yerine geçmez. Free CPU/write bütçesi geniş fanout'da tavan; measured batch/cursor ve gecikme, paid upgrade yok.

# ADR-001 — Server-owned public listings and evidence-backed extraction
Status: ACCEPTED (adopted from verified legacy decisions 1, 5, 6 and 11; 18 October 2026)

## Context
The product consumes official public-job listings. Phone-side crawlers and unsupported eligibility claims create privacy, consistency and correctness risks. Older accepted decisions separated source access, matching, inference and notification responsibilities.

## Decision
- Cloudflare Worker/D1/Queue owns official source fetching, full-text persistence, extraction, normalization, catalog revisions and notification fanout. The phone uses API/cache and opens official application links only at the user's request.
- Extract source-native structured values mechanically first. Validate them against source text and schema; call Qwen only for eligible missing/ambiguous extraction under explicit bounded budgets. Persist successful results and do not repeat inference for unchanged content/version/model contracts.
- Keep personal profile and saved listings local. If the user opts into matching alerts, send only necessary saved criteria and preferences; assistant requests are user initiated and separately bounded.
- Eligibility is three-state. Missing evidence remains unknown; multi-position criteria must not leak across sibling positions. An AI answer is not a definitive eligibility ruling.
- Reminder planning uses local saved data and rechecks quiet hours/expiry at delivery; OS delivery is best effort, never guaranteed.
- Free-tier operation is the default. No paid fallback, automatic quota upgrade, new provider or recurring monitoring without explicit user authorization.

## Consequences
Offline cache is available while the server remains authoritative. Source failures and partial extraction stay visible as gaps. Machine tests, source evidence and real device/runtime acceptance are separate gates.

## Scope
Store metadata, screenshots, experiments, release submissions and publishing procedures are excluded from this ADR and active Project Brain plan.

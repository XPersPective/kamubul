## Objective
"O zaman Mimo ve 2.6. Pro'yu yap." (user, 29.10.2026). Use Mimo v2.6 Pro for server-side notice-condition extraction while keeping the assistant model unchanged, so extraction does not consume the assistant model's provider quota.

## Steps
1. In `workers/src/extract.js`, derive an extraction-only environment from `EXTRACT_EXTERNAL_MODEL` and use it for external requests, model-version cache hashes and persisted extraction model names; preserve `EXTERNAL_AI_MODEL` for assistant calls and use the existing value when the override is absent.
2. In `workers/wrangler.jsonc`, set `EXTRACT_EXTERNAL_MODEL` to the exact provider model id `mimo-v2.6-pro` without changing `ASSISTANT_AI_MODEL` or `EXTERNAL_AI_MODEL`.
3. In `workers/test/extract.test.js`, verify that extraction sends and caches `mimo-v2.6-pro` while the assistant provider model remains unchanged.
4. Update `README.md` and `docs/SERVER_INGESTION_STRATEGY.md` so the documented extraction and assistant model split matches the deployment configuration.

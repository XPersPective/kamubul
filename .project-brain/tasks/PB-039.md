## Objective

## Steps
1. Kullanıcı developer.apple.com > Keys > + ile "KamuBul APNs" anahtarını (APNs, Sandbox & Production) oluşturur ve .p8 dosyasını indirir (ajan sır üretemez/indiremez).
2. Kullanıcı Firebase > Project settings > Cloud Messaging > KamuBul iOS > APNs Authentication Key bölümüne .p8, Key ID ve Team ID 53X3279WA3 yükler (devx8585 Google hesabı).
3. Gerçek iPhone'da TestFlight veya App Store sürümüyle Ayarlar > Sunucudan anlık bildirim açılır; Worker eşleşen ilanda FCM gönderir.
4. Sonuç `docs/RELEASES.md` iOS bölümüne yazılır.

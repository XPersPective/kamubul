## Objective
Package KamuBul's Turkish iOS localization and assistant guidance fixes as version 1.2.6 using GitHub Actions.

## Steps
1. Advance the version in pubspec.yaml for the next App Store release train.
2. In the iOS release workflow, allow an explicit processing-only candidate upload after the existing signed archive, privacy-related plist and production AdMob validations, while retaining the existing acceptance requirement for the normal upload path.
3. In lib/main.dart, defer ad initialization until the app has drawn a frame and is foregrounded. Retry a failed consent attempt on resume and prevent overlapping ad loads.
4. In lib/data/ad_consent.dart, abort ad startup if iOS could not resolve ATT, and in lib/ads_state.dart preserve the full seven-day ad-free trial.
5. In the existing listing and deduplication tests, set an explicit prune cutoff for fixed-date fixtures so historical records do not expire according to the runner clock.
6. Verify StoreKit source and product identifiers match the currently approved build.

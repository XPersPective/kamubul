# PB-018 — Hesapsız abonelik, eşleşme, outbox ve FCM

## Status
PLANNED
## Objective
Typed saved-search registry ile deterministik yeni ilan eşleşmesi; dayanıklı bounded fanout ve kişisel FCM.
## Dependencies
PB-016, PB-017
## Affected Areas
Worker registry/matching/outbox/FCM API, core matching fixtures, mobile secure credentials/token registration.
## Acceptance Criteria
- [ ] Kurulum own-record ID+secret auth; hash-only server, constant-time equivalent; rate-limit/body/max20search whitelist. Secure device storage/backups, explicit criterion upload opt-in.
- [ ] search facets indexed superset, exact predicate parity; hash-shared evaluation optional measurement sonrası. Unknown coarse field yanlış aday elemez; multi-group strict score/age/eğitim.
- [ ] effectiveFromSeq eski ilanları push yapmaz. Multi-search aynı installation+listing event tek push, matchedSearchIds. Büyük kitle match_run cursor ile yeniden başlar, tüm cihaz her Cron'da taranmaz.
- [ ] Outbox unique+lease, dueAt/cap/quiet/digest, commit before send, retry+invalid token handling. Preference version/off/delete send öncesi recheck; token change newest token; no global pending clear.
- [ ] FCM least-privilege server identity/HTTPv1/short-lived OAuth, credentials yalnız Cloudflare Secrets. Access grant için action-time onay; broad Editor key varsayılan değil.
- [ ] Timeout ambiguous acceptance ve exact-once sınırı kaydı; eventId notification tag/client dedupe; accepted !=delivered. Backlog silent truncation yok, expiry/digest politikası explicit.
- [ ] Auth private notification history bounded cursor; quiet calendar full date, Europe/Istanbul/offset migration, preferences online heartbeat only on change/due (120gün stale cleanup).
- [ ] End-to-end tek developer Android device: new matching notice, no-match/unknown sessiz, quiet/digest/off/delete, refresh token, idempotent restart. Gerçek 10k kullanıcı push testi yok.

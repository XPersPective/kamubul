## Objective
“Modern iyi bir protokolle ayrıştırıyor mu? ... Yanlış ayrıştırabiliyor mı?” Establish evidence-backed accuracy for extracted public-job requirements.

## Steps
1. Trace mechanical extraction, validation and Qwen fallback in `workers/src/` against constraint C-002/C-003.
2. Build a bounded, source-cited evaluation set in `workers/test/` covering age, education, KPSS, dates and multi-position boundaries.
3. Report per-field precision and recall with failures and unknowns; create fixes only for reproduced defects.

## Acceptance
- [ ] [machine] Extraction tests demonstrate correct values, unknowns and position separation on the evaluation set.
- [ ] [architecture] Field-level precision/recall and source evidence are reported; no unsupported accuracy claim remains.
- [ ] [security] No secret, personal profile data or access-control bypass enters fixtures or logs.

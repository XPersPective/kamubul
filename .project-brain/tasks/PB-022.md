# PB-022 — Harici AI fallback ve kullanıcı kriter asistanı

Status: BLOCKED
Dependencies: PB-016 ilgili typed sözleşme/Free ölçüm, PB-017 mobil kayıt/registry akışı. ADR-002 ürün kararı.

## Sıra

1. Kullanıcının sağlayıcı/model ve günlük/aylık harcama üst sınırını al. Resmî pricing/structured output/usage/retry/veri saklama belgelerini doğrula. Key yalnız güvenli Cloudflare Secrets akışında; sohbetten isteme. Eksik ayarda özellik disabled kalır.
2. Mevcut pipeline AI binding/3036 quota_wait/chunk checkpoint yoluna minimal harici provider ekle. Sadece gerçek Free provider günlük kota hatası fallback açar. Uygulama AI_DAILY_JOBS, busy/timeout/522/invalid JSON ayrı reason code. Ayrı atomik rezervasyon/usage ve provider/model/prompt sürümünü kaydet; başarılı hash replay çağrı yapmaz. Yapay prod kota düşürme/fixture yazma yok.
3. Bildirim kapalı veya FCM token olmayan kurulum için private assistant auth-only kayıt tasarla. Bugünkü registry PUT token gerektiriyor; auth/push ayrımı owner-secret/retention/reinstall ve mevcut client sözleşmesini korumalı. Worker CPU/D1 maliyetini ölç.
4. Private assistant endpoint: bounded message + seçili SavedSearch + baseVersion + requestId. Çıktı create/update/delete typed taslak veya clarification; mevcut validateCriteria/taxonomy kullan. Model tools/SQL/arbitrary URL/push veya doğrudan mutasyon yok. Aynı requestId replay yeniden inference yapmaz. Desteklenmeyen değerler soruya dönüşür.
5. Flutter mevcut formuna AI ile düzenle ve asistan girişini ekle. Kısa sınırlı konuşma, alan diff'i, arama adı ve off/instant/digest taslağı. Uygula mevcut local store/registry, İptal değişiklik yapmaz. Stale draft/duplicate apply korunur. Elle form aynı veriyi düzenler; ikinci etiket deposu yok.
6. Aynı matcher cache'teki Bana uygun ilanlar görünümünü günceller. Yeni arama eski ilanları yeni-ilan push'ı yapmaz; effective baseline korunur. İzin kapalıysa profil yine kaydolur, OS izni kullanıcı eylemiyle açılır. Silinen arama mevcut facet/pending cancel akışını kullanır.
7. Assistant ve ingestion ayrı budget/rate/concurrency sınırları, safe metrics. Şema/bütçe yarışları/replay/quota geçişi/fallback hata/chunk devamı/stale draft/delete/permission off/manual parity kontrolleri. Sağlayıcı hazırken sınırlı gerçek entegrasyon ve fiziksel Android testi; demo veri yok.

## Kabul

- [ ] Sağlayıcı/model/secret ve ayrı bütçeler doğrulandı; Cloudflare otomatik upgrade yok.
- [ ] Free günlük kota fallback; diğer hatalar değil. Başarılı hash yeniden çağrılmıyor, durable işler kaybolmuyor.
- [ ] FCM izni olmayan kurulum assistant kullanabiliyor; limitsiz public inference yok.
- [ ] Elle ve AI create/update/delete aynı typed kayıt/matcher kullanıyor; unknown değer uydurulmuyor.
- [ ] Taslak Uygula/İptal/stale/duplicate, bütçe yarışları ve manual parity runnable kontrolleri geçti.
- [ ] Uygun ilan görünümü/push shared corpus ve gerçek cihazda doğrulandı.

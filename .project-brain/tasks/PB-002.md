# PB-002 — Local catalogue and bookmarks

## Status
PLANNED
## Objective
Add versioned local storage, dedupe/expiry, saved announcements, filters and official application action.
## Dependencies
PB-001
## Affected Areas
`lib/`, `test/`
## Acceptance Criteria
- Listings/bookmarks survive restart/migration; failed refresh preserves data.
- Listing model carries schema-v1 structured fields (kontenjan, yaş, eğitim, KPSS, şehir, deadline, quota type) where extracted; unknown fields render explicitly as "belirtilmemiş", never guessed; any shown field exposes its quoted source sentence.
- Category/occupation/location/date filters work and official application URL is validated. Saved searches (named filter sets) can be created, edited, deleted locally and are exportable.
- Old unsaved items are pruned; saved expired items clearly marked.
## Verification
Risk: HIGH. Migration, malformed-input and persistence tests plus release smoke-check.
## Architecture Impact
Expected: YES — local data model.
## Decision Boundary
Never silently delete user bookmarks.

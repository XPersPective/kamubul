## Acceptance Criteria
- [ ] Kariyer + SBB server egress probe, İŞKUR/ilan.gov honest blocker; kaynak terms ve allowlist. Engelli kaynak proxy/telefon otomatik fallback istemez.
- [ ] Başlangıç30dk kontrollü source schedule, source lease/cursor/ETag, timeout/payload/polite retry; 5dk ancak ölçüm sonrası. Detail revalidation round-robin/eski değişiklik bulma.
- [ ] Stable source identity, semantic contentHash; duplicate/repost alias güvenilir; same hash doesn't call AI. HTML reklam/timestamp değişimi hash'i bozmaz, gerçek koşul/deadline değişimi revision artırır.
- [ ] Kalıcı processing job, lease expiry, quota_wait, bounded attempts; raw notice fetch/normalize sonrası kaybolmaz. PDF/OCR limitinde source text/unknown fallback, tahmin yok.
- [ ] Workers AI Free model pilotu: extraction+3–5 bullet summary, source quote/value checks, schema, taxonomy, fields precision>=0.95, recall raporu; >=50 labeled örnek/kaynak. Model yetersizse alan kapalı, ücretli fallback yok.
- [ ] Input/output/attempt ve UTC daily neuron reservation; measured per-notice neurons ve max notices. Consumer chat aboneliği API kotası kabul edilmez.
- [ ] Listings+immutable change/event atomik, firstSeen/published/fetched/revision ayrımı; aynı successful revision bir kez, retry aynı stored result'ı yeniden yazar ama duplicate event yaratmaz.
- [ ] Kaynak failure önceki katalog ve success time korunur; drift degraded, log secret/profile içermez.

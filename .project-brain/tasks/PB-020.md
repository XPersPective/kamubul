## Status
IN_PROGRESS
## Objective
Kullanıcı isimli typed kriter editörü, KPSS puanı/yaş grubu ve premium kişisel ilan/notification UX; mevcut tema/motion/favorileri koru.
## Dependencies

## Affected Areas
Flutter onboarding, filters/profile/saved searches, home/detail/history/source/settings, tests/goldens.
## Acceptance Criteria
- [ ] ≤4 skippable onboarding, optional profile; user search name versus keyword versus typed criterion ayrımı. Static options searchable, multi-select, KPSS numeric validation/type/year, ageAsOf refresh açıklaması.
- [ ] Önizleme cached result count; match/no_match/unknown ayrı durum; unknown için “Şartları kontrol et”, strict push vaadi yok. Edit/rename/delete, instant/digest/off, registry pending/saved/error status.
- [ ] Above-fold kısa3–5 summary, distinct requirementGroups ve quote-backed chips; kaynak, kurum/pozisyon/şehir/quota/deadline, sticky official CTA. AI label ve unknown/expired durumları.
- [ ] Cache skeleton/last update/offline, event notification center/deep-link, opt-in criteria upload explanation; Pro/ad policy korunur.
- [ ] Token-driven light/dark, interruptible motion/haptic, WCAG AA/48dp/semantics, phone/tablet/1.3x screenshot+golden; release visible response <100ms hedefi ölçülür. Uygulama AI/API yanıtını bekleyen boş ekran olmaz.
## Verification
MEDIUM (new criteria mutation HIGH): widget/save-search tests, goldens, contrast and response harness, real release-device visual pass. Eski golden reference yeni UI ile bilinçli güncellenir.
## Architecture Impact

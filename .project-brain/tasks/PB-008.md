# PB-008 — Premium UI system and polish

## Status
PLANNED
## Objective
Implement the premium UX system from target.md: M3 Expressive direction tokens and motion, skeleton loaders, transitions, haptics, deadline countdowns, evidence chips, state design and onboarding — on the accessibility hard bar.
## Dependencies
PB-002, PB-007
## Affected Areas
`lib/`, `test/`, `assets/`
## Acceptance Criteria
- Design-token-driven Material 3 theme with interruptible spring motion, shape-morph state changes and light/dark parity; no hardcoded colors in screens.
- Lists use skeleton loaders; list→detail uses hero/shared-axis transition; large-title collapsing header; every tap answers within 100 ms; haptics on save, filter commit and apply.
- Filter chips plus bottom-sheet panel with live result count before applying; detail screen shows title, kurum, şehir, kontenjan, deadline countdown badge and sticky apply CTA above the fold; conditions are scannable chips backed by quoted source sentences.
- Empty/error/offline states are plain-language with a next action; offline shows last cached data; notification soft-ask appears after the first saved search.
- Onboarding is ≤4 skippable steps creating profile and first saved search.
- Accessibility passes: WCAG AA contrast, 48dp targets, Semantics labels for TalkBack/VoiceOver, no clipping at 1.3x text scale.
## Verification
Risk: HIGH. Widget/golden tests, accessibility audit, release-device UX pass on Android and iOS.
## Architecture Impact
Expected: YES — presentation layer.
## Decision Boundary

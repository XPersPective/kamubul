## Objective
“Google politikalarına uygun mu?” Provide a safe in-app route to report a problematic AI answer and enable operator review.

## Steps
1. Read current Assistant request/response and storage paths; finish the report trust, privacy, authorization, idempotency, retention and deletion contract in a new ADR before this task becomes READY.
2. Confirm the draft/receipt persistence and backup boundary before setting this task READY.
3. Implement bounded reporting only after the contract is executable; add Worker and Flutter tests for validation, retry and failure behavior.
4. Update the privacy notice to match the implemented data flow and verify operator readback separately from tests.

## Acceptance
- [ ] [security] Report path has bounded payload/rate/idempotency, minimal data, retention/deletion and private operator access.
- [ ] [interaction] User previews and confirms one answer report; offline/failure preserves draft and retry does not duplicate.
- [ ] [accessibility] Keyboard, TalkBack and enlarged text can complete the flow.
- [ ] [integration] Real deployed response and operator readback match the documented behavior.
